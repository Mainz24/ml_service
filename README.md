# Сервис ML-Прогнозирования и Управления Балансом

## Описание Проекта

Этот сервис представляет собой веб-приложение на базе **FastAPI**, предназначенное для асинхронного выполнения задач машинного обучения. 
Он включает в себя систему управления пользователями, механизм транзакций для отслеживания использования ресурсов (кредитов) и пользовательский интерфейс на **Jinja2/HTML**.

**Ключевые возможности:**

*   **Аутентификация:** Регистрация пользователей, вход в систему (логин) с использованием JWT-токенов и защита маршрутов.
*   **Управление Балансом:** Пополнение и списание кредитов, история транзакций.
*   **ML-Задачи:** Асинхронная отправка задач модели (прогнозирования/обработки данных) через веб-форму.
*   **История Задач:** Отслеживание статуса выполнения задач и просмотр конечных результатов в UI.
*   **UI:** Чистый, современный пользовательский интерфейс на чистом CSS.

## Технологический Стек

*   **Бэкенд:** Python (FastAPI, Uvicorn)
*   **База данных:** PostgreSQL (через SQLAlchemy 2.0 с AsyncSession)
*   **Фронтенд:** HTML/CSS (Jinja2 Templates)
*   **Управление зависимостями:** Docker / Docker Compose
*   **Брокер задач:** RabbitMQ (для асинхронных ML-задач)

## Запуск Проекта (Локально с Docker Compose)

1.  **Клонируйте репозиторий:**
 
https://github.com/Mainz24/ml_service.git

2.  **Запустите сервисы:**
    Используйте Docker Compose для сборки образов и запуска всех контейнеров (приложение FastAPI, база данных Postgres, Nginx, брокер задач):

    docker-compose up --build


4.  **Доступ к приложению:**
    После того как все контейнеры запустятся (это может занять некоторое время при первом запуске), сервис будет доступен по адресу:

http://localhost/login

## Основные Эндпоинты UI

*   **Главная страница:** `/` (требует аутентификации)
*   **Регистрация:** `/register`
*   **Вход в систему:** `/signin`
*   **Управление балансом:** `/balance_ui`
*   **Задачи ML-модели:** `/tasks_ui`
